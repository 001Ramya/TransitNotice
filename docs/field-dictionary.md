# Field dictionary and source mapping

| TransitNotice field | Why it exists | MBTA source mapping | CTA source mapping |
| --- | --- | --- | --- |
| `notice_id` | Internal UUID used by the database and UI | Generated by TransitNotice | Generated by TransitNotice |
| `external_id` | Stable source identity for idempotent updates | `data[].id` | `CTAAlerts.Alert[].AlertId` |
| `agency` | Data origin | MBTA adapter | CTA adapter |
| `route_ids` | Search/filter affected services | `attributes.informed_entity[].route` | `ImpactedService.Service[].ServiceId` |
| `area` | Human-friendly affected place | informed stop IDs or routes | affected `ServiceName` values |
| `source_url` | Provenance link | `attributes.url` | `AlertURL` |
| `advisory_type` | Consistent filter label | normalized effect/cause | normalized impact/severity class |
| `summary` | Scannable card/title text | header / short header / banner | headline / short description |
| `content_text` | Full readable notice body | description | full or short description |
| `published_at` | Source creation time where supplied | `created_at` | not supplied by detailed feed |
| `valid_from` | Advisory service start | earliest active-period start | `EventStart` |
| `valid_to` | Advisory service end | latest active-period end | `EventEnd`, nullable |
| `status` | Current application status | derived from dates and withdrawal state | derived from dates and withdrawal state |
| `last_observed_at` | Most recent collection attempt that included this record | assigned at persistence | assigned at persistence |
| `last_confirmed_at` | Latest successful source confirmation | assigned at persistence | assigned at persistence |
| `revision_number` | Immutable order of meaningful changes | calculated from content hash | calculated from content hash |
| `change_summary` | Explains the latest revision | field comparison | field comparison |

## Normalization

The source adapters strip markup from descriptions, remove duplicate route IDs, convert known time zones to timezone-aware timestamps and map varied source wording into a small set of advisory labels:

- `ROUTE_DIVERSION`
- `SERVICE_INTERRUPTION`
- `DELAY`
- `ACCESSIBILITY`
- `PLANNED_WORK`
- `SERVICE_ADVISORY`

The original readable summary and content are retained alongside the normalized label.
